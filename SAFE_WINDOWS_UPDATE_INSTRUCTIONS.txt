HOW TO UPDATE YOUR WINDOWS LAPTOP:
------------------------------------------------------------------------------
Option A (In-Place Update — Recommended):
  1. Close Zamzam Foods on your Windows laptop if it is running.
  2. Extract all files from this ZIP directly into your existing Zamzam Foods folder.
  3. When Windows asks to replace files, click "Replace the files in the destination".
     (Your "db.sqlite3" will stay untouched because this zip does NOT contain one!)
  4. Double-click "1_START_ZAMZAM_APP.bat" to start!

Option B (Fresh Folder):
  1. Extract this ZIP into a new folder on your Windows laptop (e.g. C:\ZamzamFoods).
  2. Copy your existing "db.sqlite3" file from your old folder into this new folder.
  3. Double-click "1_START_ZAMZAM_APP.bat" to start!
